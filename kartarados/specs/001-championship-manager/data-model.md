# Data Model: Kartarados Championship Manager

**Date**: 2026-01-26  
**Database**: Supabase PostgreSQL

## Entity Relationships

```
Admin (1) ──< manages >── (N) Season
Season (1) ──< contains >── (N) Cup
Season (1) ──< contains >── (N) Race
Cup (1) ──< contains >── (N) Race
Driver (1) ──< participates in >── (N) RaceResult
Race (1) ──< has results >── (N) RaceResult
```

## Entities

### Admin

**Table**: `admins`  
**Description**: Authenticated users who can manage championships

**Fields**:
- `id` (UUID, Primary Key) - Auto-generated by Supabase Auth
- `email` (TEXT, Unique, Not Null) - Admin email address
- `created_at` (TIMESTAMP) - Account creation timestamp
- `is_first_admin` (BOOLEAN, Default: false) - Flag for first admin account
- `created_by` (UUID, Foreign Key → admins.id) - Admin who created this account (null for first admin)

**Relationships**:
- One admin can create many other admins (self-referential)
- Admins manage all other entities (application-level, not database-level)

**Validation Rules**:
- Email must be unique across all admins
- First admin account must have `is_first_admin = true`
- Password stored by Supabase Auth (not in this table)

**Indexes**:
- `email` (unique index)

---

### Season

**Table**: `seasons`  
**Description**: Championship seasons, typically one per year

**Fields**:
- `id` (UUID, Primary Key)
- `name` (TEXT, Not Null) - Season name (e.g., "2026 Championship")
- `start_date` (DATE, Not Null) - Season start date
- `end_date` (DATE, Not Null) - Season end date
- `is_ongoing` (BOOLEAN, Not Null, Default: false) - Marks the season as the ongoing season
- `accent_color` (TEXT, Not Null) - Hex color code for UI theming (e.g., "#000000")
- `created_at` (TIMESTAMP) - Creation timestamp
- `updated_at` (TIMESTAMP) - Last update timestamp

**Relationships**:
- One season contains many cups (optional)
- One season contains many races (directly or via cups)

**Validation Rules**:
- `end_date` must be >= `start_date`
- `accent_color` must be valid hex color format (#RRGGBB)
- Name cannot be empty

**Indexes**:
- `start_date`, `end_date` (for active season queries)
- `is_ongoing`, `start_date` (for ongoing season selection)

---

### Cup

**Table**: `cups`  
**Description**: Optional events within a season

**Fields**:
- `id` (UUID, Primary Key)
- `season_id` (UUID, Foreign Key → seasons.id, Not Null)
- `name` (TEXT, Not Null) - Cup name
- `start_date` (DATE, Not Null) - Cup start date
- `end_date` (DATE, Not Null) - Cup end date
- `created_at` (TIMESTAMP)
- `updated_at` (TIMESTAMP)

**Relationships**:
- Many cups belong to one season
- One cup contains many races

**Validation Rules**:
- `end_date` must be >= `start_date`
- Cup dates must fall within parent season's date range
- Name cannot be empty

**Indexes**:
- `season_id` (foreign key index)

---

### Driver

**Table**: `drivers`  
**Description**: Racing drivers

**Fields**:
- `id` (UUID, Primary Key)
- `email` (TEXT, Unique, Not Null) - Driver email (unique identifier)
- `name` (TEXT, Not Null) - Full name
- `nickname` (TEXT) - Optional nickname
- `birth_date` (DATE) - Date of birth
- `sex` (TEXT) - Gender (e.g., "Male", "Female", "Other")
- `blood_type` (TEXT) - Blood type (e.g., "O+", "A-")
- `picture_url` (TEXT) - URL to profile picture in Supabase Storage
- `created_at` (TIMESTAMP)
- `updated_at` (TIMESTAMP)

**Relationships**:
- One driver participates in many race results

**Validation Rules**:
- Email must be unique across all drivers
- Email must be valid format
- Name cannot be empty
- Picture URL must be valid URL format (if provided)

**Indexes**:
- `email` (unique index)

---

### Race

**Table**: `races`  
**Description**: Individual race events

**Fields**:
- `id` (UUID, Primary Key)
- `season_id` (UUID, Foreign Key → seasons.id, Not Null) - Direct season assignment
- `cup_id` (UUID, Foreign Key → cups.id, Nullable) - Optional cup assignment
- `name` (TEXT, Not Null) - Race name
- `location` (TEXT, Not Null) - Location/circuit name
- `race_datetime` (TIMESTAMP, Not Null) - When the race occurs/happened
- `affects_championship` (BOOLEAN, Default: true) - Whether race affects overall championship
- `created_at` (TIMESTAMP)
- `updated_at` (TIMESTAMP)

**Relationships**:
- One race belongs to one season (directly)
- One race optionally belongs to one cup
- One race has many race results

**Validation Rules**:
- Race must belong to either season directly OR to a cup (cup implies season)
- If `cup_id` is set, `season_id` must match cup's season
- Name and location cannot be empty
- `race_datetime` must be valid timestamp

**Indexes**:
- `season_id` (foreign key index)
- `cup_id` (foreign key index, nullable)
- `race_datetime` (for sorting/filtering)

---

### RaceResult

**Table**: `race_results`  
**Description**: Driver's performance in a specific race

**Fields**:
- `id` (UUID, Primary Key)
- `race_id` (UUID, Foreign Key → races.id, Not Null)
- `driver_id` (UUID, Foreign Key → drivers.id, Not Null)
- `finish_position` (INTEGER, Not Null) - Final position (1, 2, 3, etc.)
- `best_lap_time` (TEXT) - Best lap time (format: "MM:SS.mmm" or "HH:MM:SS.mmm")
- `grid_start_position` (INTEGER) - Starting grid position (1 = pole position)
- `is_disqualified` (BOOLEAN, Default: false) - Disqualification flag
- `comments` (TEXT) - Additional comments/notes
- `created_at` (TIMESTAMP)
- `updated_at` (TIMESTAMP)

**Relationships**:
- Many race results belong to one race
- Many race results belong to one driver

**Validation Rules**:
- `finish_position` must be > 0
- `grid_start_position` must be > 0 (if provided)
- Driver cannot have multiple results for the same race (unique constraint)
- `best_lap_time` must be valid time format (if provided)

**Indexes**:
- `race_id` (foreign key index)
- `driver_id` (foreign key index)
- `(race_id, driver_id)` (unique composite index - one result per driver per race)
- `finish_position` (for sorting)

---

### Penalty

**Table**: `penalties`  
**Description**: Penalties applied to a driver in a race

**Fields**:
- `id` (UUID, Primary Key)
- `race_result_id` (UUID, Foreign Key → race_results.id, Not Null, On Delete: CASCADE)
- `penalty_type` (TEXT, Not Null) - Standard type or "custom"
- `penalty_name` (TEXT, Not Null) - Name of penalty (standard type name or custom name)
- `point_deduction` (INTEGER, Not Null) - Points to deduct (negative value)
- `count` (INTEGER, Default: 1) - Number of times this penalty was applied

**Relationships**:
- Many penalties belong to one race result

**Validation Rules**:
- `point_deduction` must be negative (or 0)
- `count` must be > 0
- Standard penalty types: "disqualification" (-8), "cone_tire_warning" (-2), "race_direction_warning" (-4), "stop_and_go" (-6), "missing_club_shirt" (-2)
- Custom penalties must have `penalty_type = "custom"` and custom `penalty_name`

**Indexes**:
- `race_result_id` (foreign key index)

## Database Constraints

### Foreign Key Constraints
- `cups.season_id` → `seasons.id` (CASCADE on delete)
- `races.season_id` → `seasons.id` (RESTRICT on delete - prevent if has results)
- `races.cup_id` → `cups.id` (CASCADE on delete)
- `race_results.race_id` → `races.id` (CASCADE on delete)
- `race_results.driver_id` → `drivers.id` (RESTRICT on delete - prevent if has results)
- `penalties.race_result_id` → `race_results.id` (CASCADE on delete)

### Unique Constraints
- `admins.email` (unique)
- `drivers.email` (unique)
- `(race_results.race_id, race_results.driver_id)` (one result per driver per race)

### Check Constraints
- `seasons.end_date >= seasons.start_date`
- `cups.end_date >= cups.start_date`
- `race_results.finish_position > 0`
- `penalties.point_deduction <= 0`
- `penalties.count > 0`

## Row Level Security (RLS) Policies

### Admins Table
- Admins can read all admin records
- Only first admin or admins with permission can create new admins
- Admins can update their own record (password change)

### Seasons, Cups, Races, Drivers Tables
- Public: Read-only access (for public rankings)
- Admins: Full CRUD access

### Race Results, Penalties Tables
- Public: Read-only access (for rankings calculations)
- Admins: Full CRUD access

## Data Migration Considerations

1. **First Admin Creation**: Manual creation in Supabase Auth dashboard, then insert into `admins` table with `is_first_admin = true`
2. **Default Season**: Optional - create a default season for initial setup
3. **Image Migration**: Driver pictures uploaded to Supabase Storage (`driver-pictures` bucket), URLs stored in `drivers.picture_url`, bucket must allow public reads and app origins for CORS

## Performance Considerations

1. **Indexes**: All foreign keys and frequently queried fields are indexed
2. **Query Optimization**: Use Supabase query builder for efficient joins
3. **Caching**: Client-side caching of calculated rankings
4. **Pagination**: Implement pagination for large result sets (drivers, races)
